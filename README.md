# 📝 Weekly App

A modern, lightweight desktop task and schedule manager built with Python and [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter). Features a clean, customizable interface with support for macOS and Windows.

---

## ✨ Features

* **Modern GUI:** Built with CustomTkinter for sleek, system-matching visuals.
* **Cross-Platform:** Available for both **macOS** and **Windows**.
* **Lightweight & Fast:** Starts up instantly with minimal system resource usage.
* **Persistent Tasks:** Keeps track of your schedule and tasks between sessions.

---

## 🛠️ Built With

* **Language:** Python 3.10+
* **GUI Framework:** [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter)
* **Packaging:** PyInstaller

```bash
